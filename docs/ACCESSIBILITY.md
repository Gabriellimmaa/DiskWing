# Interface acceptance

The overview is the non-blocking starting guide: choose a folder to inspect names/sizes, explore recognized caches, then review a concrete action. Opening the app grants no mutation or background monitoring. Permissions explain the affected area; denied access remains a partial/unknown result. Chrome and installed environments remain protected.

Choose System, Português (Brasil) or English in Settings. Literal text and interpolated file names are separate; names/paths/tool versions remain verbatim. Both application messages and byte/date presentation follow the selected locale. Native platform error text follows macOS.

Keyboard checks: Command-O chooses a folder, Command-R refreshes, Command-1 through Command-5 change sections. Native Table selection/primary action opens folders, menus expose the same file actions, Tab/Shift-Tab move between controls, Escape cancels a review, Return confirms only the visible review. Verify page navigation, search, filters, permission errors and recovery without a mouse.

VoiceOver acceptance on each supported language: sidebar sections, disk/free-space descriptions, scan progress/cancellation, search/table headers/rows, unknown/partial states, selected-item inspector, source/destination facts, explicit release-source toggle, review/cancel/default action, history/recovery and settings. Confirm reading order, visible focus, understandable labels, no information solely by color and useful text at large system sizes.

Automated catalog/native-control checks and an accessibility-tree inspection are evidence of structure. They do not substitute for operating the complete workflow with VoiceOver. Record tester, build, language, macOS, results and issues in private beta evidence before marking the gate verified.
