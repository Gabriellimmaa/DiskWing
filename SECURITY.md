# Security and data-loss reports

DiskWing is an early local alpha. No stable security support window or public notarized release is available yet.

Use GitHub's private vulnerability reporting for this repository if available. If unavailable, open a minimal issue asking for a private contact channel, without file contents, personal paths, credentials, or exploit details. Do not upload settings or migration archives publicly.

Include the app revision, macOS version, affected operation, whether a disposable sample reproduces it, and preservation/recovery state. Redact exported reports and logs before sharing.

The app analyzes local metadata and performs only reviewed operations. External storage can disappear mid-operation. Developer ID signing, notarization, update delivery, and broader platform validation remain pending.
